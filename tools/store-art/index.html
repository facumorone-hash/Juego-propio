VOIDLINGGENERADOR DE ARTE DE TIENDA

Reglas de Steam: las cápsulas de la tienda solo pueden llevar arte y el logo/nombre del juego (nada de frases, citas, premios ni descuentos). Por eso las versiones para Steam van sin frase; activa "Mostrar frase" para las variantes de itch.io, redes y prensa.
Cada imagen se compone con el render del juego (sprites procedurales, fondo y agujero negro de js/render.js) más capas de arte clave en alta resolución. La misma semilla siempre da la misma imagen. "Descargar todo" incluye las versiones sin frase (Steam) y con frase EN/ES, el .ico y los extras de prensa. Exportación automática: cd tools/store-art && npm install && node export.js.
